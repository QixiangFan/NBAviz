# Interim data

Generated by `python build_interim_data.py` from the raw cache in `data/raw/`: Basketball-Reference ([Kaggle `sumitrodatta/nba-aba-baa-stats`](https://www.kaggle.com/datasets/sumitrodatta/nba-aba-baa-stats) v56) with NBA.com team and player ids. Not used by the website; git-ignored. Seasons are starting years (2025 = 2025-26).

## Files

### `teams.csv`

One row per team per season since 1979-80: data/clean/team_seasons.csv with every Basketball-Reference column. 1,314 rows.

| Column | Meaning |
|---|---|
| `team_id / team / team_name` | NBA.com franchise id, abbreviation and name that season |
| `bref_team / bref_abbr` | Basketball-Reference name and abbreviation (the join key with season) |
| `playoffs` | Made the playoffs |
| `ppg ... efg` | As in data/clean/team_seasons.csv |
| `ortg / drtg / net_rtg / pace` | Basketball-Reference's ratings and pace (its possession estimate) |
| `srs / mov / ts_pct / age` | Simple rating system, margin of victory, true shooting %, average player age |
| `min ... pts` | Season totals |

### `players.csv`

Basketball-Reference season totals and advanced stats, one row per player-season since 1979-80 (no minimum minutes). 20,550 rows.

| Column | Meaning |
|---|---|
| `bref_id` | Basketball-Reference player id (the slug in the player's page URL) |
| `nba_player_id` | NBA.com player id, blank if the player never played in 1996-97 or later |
| `team / last_team` | Teams in the order played (e.g. DAL/LAL) and the final one |
| `gp ... fta` | Season totals |
| `per / ts_pct / usg_pct` | Player efficiency rating, true shooting %, usage rate (0-1) |
| `ows / dws / ws / ws_48` | Win shares (offensive, defensive, total, per 48 minutes) |
| `obpm / dbpm / bpm / vorp` | Box plus/minus and value over replacement player |

### `player_ids.csv`

Basketball-Reference id ↔ NBA.com id, one row per player who played in 1996-97 or later. 2,859 rows.

| Column | Meaning |
|---|---|
| `player / nba_name` | Name as Basketball-Reference and NBA.com spell it |
| `first_season / last_season / seasons` | Seasons linked (1996-97 on) |
| `match` | name, or games+points when the names differ (see the cleaning rules) |

### `awards.csv`

Award voting since 1955-56, one row per player with votes. 3,362 rows.

| Column | Meaning |
|---|---|
| `award` | mvp, roy, dpoy, smoy, mip or clutch_poy |
| `first_place_votes / pts_won / pts_max` | Voting points |
| `share` | pts_won / pts_max |
| `winner` | Won the award (co-winners possible) |

### `all_league_teams.csv`

All-NBA, All-Defensive and All-Rookie selections. 2,034 rows.

| Column | Meaning |
|---|---|
| `selection` | All-NBA, All-Defense or All-Rookie |
| `team_rank` | 1st, 2nd or 3rd team |
| `position` | Position slot, where the team had one |

### `all_stars.csv`

All-Star selections, one row per player per season. 1,850 rows.

| Column | Meaning |
|---|---|
| `all_star_team` | The side he was picked for that year (e.g. East, Team LeBron) |
| `replaced` | Named but replaced (injury) |

## Cleaning rules

1. Basketball-Reference tables come from a pinned Kaggle version (config.BREF_VERSION). ABA and BAA rows are dropped, and seasons are renamed to their starting year (Basketball-Reference's 2026 = 2025-26).
2. Players: a traded player keeps Basketball-Reference's combined row (2TM/3TM, or TOT before 2024-25), with every team he played for listed in order.
3. Player ids are linked season by season from 1996-97, when NBA.com's player tables start: first by name (accents, punctuation and Jr./III suffixes ignored; same games played when two players share a name), then by the same games played and points within 5 for nicknames and spellings. A link applies to the player's whole career.
